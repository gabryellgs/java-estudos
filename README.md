# Estudos Java

Repositório com exercícios e projetos de aprendizado em Java.

## Estrutura do Projeto

- **Lógica** - Exercícios básicos de lógica de programação
- **POO** - Conceitos de Programação Orientada a Objetos
- **Herança e Polimorfismo** - Exercícios avançados de OOP

## Como Executar

Cada arquivo pode ser compilado e executado individualmente com:

```bash
javac NomeDoArquivo.java
java NomeDoArquivo
```
